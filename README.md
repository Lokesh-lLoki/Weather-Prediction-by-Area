Weather Prediction by Area Using Machine Learning

A location-based weather prediction dashboard built with Python,

Machine Learning, and Streamlit. Users can search for a city and

explore a seven-day weather prediction generated by a location-specific

machine-learning pipeline, alongside a seven-day forecast retrieved from

the Open-Meteo API.

Project note: The machine-learning output is experimental and

intended for learning and demonstration. It is not an official

meteorological warning or forecast. Model performance can vary by

location and weather conditions.



Features

\- Search for a city and retrieve its geographic coordinates.

\- Download historical daily weather data for the selected coordinates.

\- Prepare weather data and engineer time-series features, including

&#x20; calendar features, lag values, and rolling statistics.

\- Train location-specific regression models.

\- Generate a seven-day experimental ML prediction.

\- Retrieve a separate seven-day Open-Meteo forecast.

\- View forecast tables, temperature and rainfall charts, and summary

&#x20; metrics.

\- Download forecast data as CSV.

Technology Stack

\- Language: Python

\- Dashboard: Streamlit

\- Data processing: Pandas, NumPy

\- Machine learning: Scikit-learn

\- Visualization: Matplotlib

\- Weather data and geocoding: Open-Meteo APIs

Getting Started

1\. Clone the repository

git clone https://github.com/YOUR-USERNAME/weather-prediction-by-area.git

cd weather-prediction-by-area

Replace YOUR-USERNAME with your GitHub username.

2\. Create and activate a virtual environment

Windows (Command Prompt):

python -m venv .venv

.venv\\Scripts\\activate

macOS / Linux:

python3 -m venv .venv

source .venv/bin/activate

3\. Install dependencies

pip install -r requirements.txt

4\. Run the Streamlit application

From the repository root:

python -m streamlit run app/app.py

Open the local URL displayed in the terminal, usually

http://localhost:8501.

Data Sources

This project uses the following Open-Meteo services:

\- Geocoding API: Converts a city name into latitude and longitude.

\- Historical Weather API: Supplies historical daily weather data

&#x20; used for model training.

\- Forecast API: Supplies a separate seven-day weather forecast for

&#x20; comparison.

See the Open-Meteo documentation for

API details and data availability.

Machine-Learning Workflow

1\. Retrieve historical daily weather observations for the selected

&#x20;  coordinates.

2\. Clean and prepare the weather data.

3\. Create time-based, lag, and rolling-window features.

4\. Build supervised training examples for multiple forecast horizons.

5\. Train regression models for weather variables.

6\. Generate an experimental seven-day prediction using the latest

&#x20;  available weather context.

The application also retrieves an Open-Meteo forecast independently. The

ML prediction and API forecast are separate outputs; they should not be

treated as interchangeable or as a verified accuracy comparison.

Deploy on Streamlit Community Cloud

1\. Push this repository to GitHub.

2\. Sign in to Streamlit Community Cloud.

3\. Choose Create app and select this GitHub repository and branch.

4\. Set the main file path to:

&#x20;  app/app.py

5\. Deploy the app.

6\. After deployment, test city search and forecast generation.

Make sure requirements.txt is in the repository root and all imports

use paths that work from the repository root.
